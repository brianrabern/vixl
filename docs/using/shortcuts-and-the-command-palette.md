# Shortcuts and the command palette

App shortcuts are listed in Settings > General under Keyboard shortcuts.

Cmd/Ctrl+K opens the command palette, including while typing. Cmd/Ctrl+N opens New Agent, except while typing in an input, [Monaco](https://microsoft.github.io/monaco-editor/), or a terminal. Cmd/Ctrl+B toggles the left sidebar. Cmd/Ctrl+Shift+B toggles the right workbench. Esc leaves Settings (and also goes Home from a project page).

New Agent is the sidebar header button and Cmd/Ctrl+N. Both push `/`.

## Editor tab (active editor only)

Cmd/Ctrl+S saves the Monaco buffer. Cmd/Ctrl+Shift+F opens Find and replace. Cmd/Ctrl+Shift+H opens the same pane with replace expanded.

## Chat input

Enter sends. Shift+Enter splits a line.

## Command palette

Open it from sidebar Search or Cmd/Ctrl+K. Placeholder: Search projects, chats, and actions.

Tabs: All, Agents, Actions, Settings.

The All tab groups items as Actions, Projects, Chats, Pinned, Settings.

Actions are New Agent, Open Settings, Open Terminal, and Open Editor (`README.md` when a project is active).

Projects lists fleet names. Chats lists titles with the project name as subtitle. Pinned lists pinned chats. Settings lists General, Graphs, MCP, Providers, Models, LSP, Permissions, Plans, Skills, Agents, Rules.

The Agents tab contains New Agent plus chat and pinned rows. The Actions tab contains the other actions plus projects. The Settings tab contains the settings sections.
